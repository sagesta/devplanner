# DevPlanner Everyday Use Review

## Main Use Of Inbox

Inbox is the triage buffer. It is where captured work lives before it becomes a commitment.

Use it to:
- collect rough tasks from Brain dump, imports, or quick adds
- clarify priority, area, due date, energy, depth, recurrence, tags, and subtasks
- decide whether a task should move into a sprint
- keep Today and the active sprint clean

Do not use Inbox as the daily execution list. If a task is ready to do, move it into a sprint or schedule it for Today.

## Everyday Flow

1. Goals: set direction across short, mid, and long-term horizons.
2. Brain dump: capture loose thoughts quickly.
3. Inbox: clarify and filter captured work.
4. Sprints: commit a small set of tasks to the week.
5. Today: execute the active work block, timer, and daily task list.
6. Board: move active sprint work through Todo, In progress, and Done.
7. Timeline: repair the schedule when reality changes.
8. Table: bulk-edit, sort, or clean up large task sets.
9. Insights: review capacity, progress rings, peak work windows, and rollover suggestions.
10. Review: close the loop with wins, carryover, next intentions, and a new sprint.
11. Settings: configure areas, capacity, calendar sync, focus preferences, and AI.

## Suitability Verdict

The app is suitable for everyday use as a personal execution system. Its strongest pattern is a full loop from capture to review, backed by practical daily tools: Brain dump, Inbox triage, sprint commitment, Today execution, timer tracking, rollover proposals, and weekly review.

The main risk is clarity. The app has many capable surfaces, so users need the loop reinforced in page headers, empty states, and onboarding. This pass tightened that by making Inbox explain its role and by wiring Goals into AI context.

## Recommended Next Product Work

- Add empty-state coaching to every major route.
